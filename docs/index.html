Methods & sources.

Data is fetched on the server, never in the browser: a scheduled job pulls the public API hourly, rebuilds this static page, and publishes it. The page you are reading is a snapshot from 25 Nov 2026, 11:13 UTC; the next rebuild is within the hour.

Endpoints used, for Tempo (chain 4217) and Base (chain 8453):

  • /api/market/stats?chainId=...
  • /api/stats/breakdowns?chainId=...
  • /api/stats/platform-time-series?chainId=...&range=...&bucket=...
  • /api/stats/activity-heatmap?chainId=...&range=...&dimension=...
  • /api/stats/activity-feed?chainId=...&limit=...
  • /api/tasks?chainId=...&sort=newest&limit=100&cursor=...

Derived figures are computed from the raw rows at build time: distinct posters per week (requester addresses grouped by ISO week), poster concentration (tasks per requester), and open-task wait (createdAt to the data-as-of time). Amounts are base units of a 6-decimal stablecoin; dollars = units / 1,000,000.

Two honest caveats. First, the API returns platform-wide figures for the time series, breakdowns, heatmap and feed whichever chainId is asked — only market/stats differs per chain — so those views are shown once and labelled platform-wide. Second, the task-list walk covers the last 10 weeks (1,276 tasks); the earliest week may be partial.

No wallet connection, no login, no analytics that collect personal data. Wallet addresses are shown truncated and no names are attached to them.
